## Overview

CatchTheInsect is a lightweight web game where players must catch insects that appear on the screen as quickly as possible. Every insect caught increases the challenge by spawning more insects, making the game progressively harder. The objective is simple: survive as long as possible while achieving the highest score.

---

## Features

- Fast-paced and addictive gameplay
- Increasing difficulty over time
- Score tracking
- Responsive design
- Smooth animations
- Lightweight with no external dependencies
- Runs directly in the browser
- No installation required

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## Gameplay

1. Start the game.
2. Choose your insect.
3. Catch insects by clicking on them.
4. Each successful catch increases your score.
5. More insects spawn as the game progresses.
6. Try to achieve the highest possible score.

## Getting Started

### Clone the repository


```bash
cd CatchTheInsect
```

### Run locally

Simply open `index.html` in your preferred browser.

